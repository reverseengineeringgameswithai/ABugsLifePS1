# Phase 3 semantic architecture frontier

This Canon page indexes the pristine-game architecture map without turning its
bounded unknowns into solved subsystem behavior. The authoritative machine report
is analysis/phase3_ownership_graph.json, regenerated by
python3 tools/phase3_ownership_graph.py and guarded by
tests/test_phase3_ownership.py.

The report maps each Phase 1 mechanic to functions, state, assets, overlay,
readers, writers, and lifecycle evidence or to a structured missing-link frontier.
It is joined from the pristine function census, symbols, semantic-state registry,
scene/overlay map, and retained runtime evidence. A function address alone is not
a complete semantic frontier.

MOD consumption contract: use only rows whose owners, widths/domains, lifecycle,
and downstream consumers meet the row’s recorded confidence. Do not treat a
bounded frontier as permission to extend a native selector or to install a hook.

[[SYS_a07_spin_external_lead]] and [[SYS_thud_bug_bar_boss]].

# A Bug's Life RE Vault

This vault is now organized around the migration structure.

- [[Canon Index]]: original-game reverse-engineering findings.
- `Mods/`: intentional game changes and active mod behavior.
- `Experiments/`: runtime tests, breakpoints, patch attempts, and save-state evidence.
- `Sessions/`: chronological handoffs and work history.
- `Archive/`: superseded, wrong, or unsorted legacy notes preserved for provenance.
- `_Revamp/`: audit, migration map, conflicts, source coverage, and validation records.

Do not promote Archive claims into Canon without stronger evidence. Canon describes the original game; Mods describe changes.
